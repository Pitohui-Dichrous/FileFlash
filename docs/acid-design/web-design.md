# 网页视觉

基于 0.1.10 重新构图，保留原有配对、系统快捷指令、文件上传下载、文字、任务与诊断流程。

- Anton 的 `FILE / FLASH` 两行错位字标承担主视觉，中文保持系统字体；不拉伸中文或混入虚构的设备指标。
- 页面用开放细线和真实章节编号组织。宽屏将发送动作与接收清单拆为不等宽两列，手机重排为上下布局；文字页采用编辑区与记录区双列。
- 主色面、操作色与中性区域分开定义。浅色为黄绿主面、黑色操作；深色为黑主面、黄绿大字和操作。中性灰的 RGB 三通道相同。电蓝用于连接入口、焦点与章节选择反馈。
- 表单、进度、错误、媒体入口和断开入口沿用原 ID。已有提示压为短句，必要错误与权限信息保留。
- 所有字体、图标离线打包。Lucide SVG 的原几何嵌入页面 symbol，原脚本继续通过相同 symbol ID 使用；无需外网图标请求。

| 角色 | 深色 | 浅色 |
| --- | --- | --- |
| 画布 | `#000000` | `#F2F2F2` |
| 内容面 | `#171717` | `#FFFFFF` |
| 字段面 | `#232323` | `#E5E5E5` |
| 主视觉面 / 字 | 黑 / `#D7FF00` | `#D7FF00` / 黑 |
| 主要操作 / 字 | `#D7FF00` / 黑 | 黑 / `#D7FF00` |
| 连接与选择反馈 | `#244CFF` | `#244CFF` |

参考 [Kurppa Hosk — Bungie](https://www.kurppahosk.com/work/bungie) 的实际图形案例：密集窄体大字与安静区域对照、不等宽图形切块、有限高亮色面积。仅借鉴构图关系，不使用其商标、游戏图像或身份标识。

字体及图标的来源与完整许可见同目录资产说明及 APK 中的 `assets/licenses/`。
