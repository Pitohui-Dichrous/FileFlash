# FileFlash

Android / iPhone 局域网文件与文字互传。免费、无账号、无广告，手机使用时不需要互联网。

Android 安装 APK；iPhone 用 Safari 扫码使用。另一台 Android 可以安装同一 APK，通过应用内扫码连接。文件保持原始内容，网页资源全部打包在 APK 中。

## 安装与使用

1. 在 Android 14 或更新系统安装 `FileFlash-0.1.1.apk`；系统提示时允许本次安装来源。
2. 两台设备连接同一个允许设备互访的 Wi-Fi。
3. Android 打开 FileFlash，在“共享”点击“开启”，允许系统请求的必要权限。
4. iPhone 用相机扫描二维码，在 Safari 打开；Android 在“连接”中点击“扫码连接”。也可复制完整连接链接，粘贴到另一台 Android。
5. 主机点击“添加文件”，接收方点击“下载”。反向发送时，在接收方选择文件即可，无须交换角色。“文字”中可以直接发送和复制内容。

Android 收到的文件保存在 **下载 / FileFlash**。在“记录 → 已接收”可以打开文件。文件成功保存、保存记录持久化且能重新读取后，应用自动释放私有副本；主机继续从下载目录共享，无须长期保存两份。

0.1.1 不生成图片或视频的磁盘缩略图缓存。“记录”页可查看临时文件占用，确认后清理闲置断点，或丢弃单个暂停/失败任务；原文件和已保存的下载文件保留。自动清理以 **256 MiB** 为闲置续传数据目标，通常保留 **24 小时**；正在处理、最近 30 分钟内使用和等待保存的完整文件受保护，因此不是全部存储的硬上限。清理只在应用进程运行及下次启动时执行。

卸载会清除应用私有临时数据和设置；**已接收的用户文件仍保留在下载目录**。详细规则与源码审查范围见 [存储与隐私](STORAGE_PRIVACY.md)。

断开客户端可在“已配对设备”操作；“停止”会撤销全部当前会话和旧二维码凭据。

## 续传与实际限制

- 上传按 2 MiB 分块校验，完成后再次验证完整 SHA-256。任务失败不会标成完成。
- Safari 页面重载后，重新选择原文件才能继续；客户端会校验原文件内容。请保留浏览器的网站数据，服务重启后重新扫码，再选择原文件恢复任务。
- 主机会复用端口；如果 IP 改变，或端口冲突迫使连接地址改变，Safari 无法读取旧地址的网站数据，可能需要从头上传。已保存的部分数据仍可由主机取消清理。
- Safari 下载由系统下载管理器保存。网页不能确认最终保存位置，也不保证 Safari 锁屏、后台上传或自动恢复下载。
- Android 的前台通知显示传输状态；系统省电、强制停止或长时间后台限制仍可能中断任务。回到应用后重新开启、配对和重试。
- 原生客户端“暂停”会停止网络传输并保留断点，便于重试；主机取消未完成接收任务会删除对应临时数据。断点被清理后需要重新发送，网页会明确提示。
- 从最近任务列表划走应用不会主动删除断点或停止正在运行的传输服务；需要结束共享和传输时，点击应用或通知中的“停止”。系统仍可能终止服务，下次打开后重新连接并重试。
- Android 发布文件到系统下载目录时会短暂产生副本，接收设备应预留约文件大小 **2 倍**的可用空间；完成可靠保存后自动释放私有副本。保存失败时保留完整接收数据供重试，不为压缩缓存丢失唯一副本。
- 文件大小不设固定 GB 上限；真实上限受可用空间、文件提供器、浏览器及文件系统约束。文字单条最多 512 KiB，超出会明确报错。
- 使用可信网络：本版本是 **未加密 HTTP**。配对令牌用于访问控制，不代表内容加密。获准连接的设备共享同一传输空间。
- 访客网络、公共 Wi-Fi 的终端隔离可能阻止连接。热点模式尚未进行真实手机测试。

## 构建

需要 JDK 17+、Android SDK Platform **37.0** 和 Build Tools **37.0.0**。工程固定 AGP 9.2.0、Gradle 9.4.1、Kotlin 2.2.10；Gradle Wrapper 已包含并校验发行包摘要。

在 Android Studio 打开项目，安装所需 SDK；或者设置 `JAVA_HOME`、`ANDROID_HOME`，然后运行：

```powershell
.\gradlew.bat :app:assembleDebug :core:test :app:lintDebug
```

调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。也可双击 `BUILD.cmd`，生成后复制至 `dist`。首次构建需要联网下载公开依赖；手机传输不需要互联网。源码包不包含本机构建缓存、SDK、测试大文件或签名私钥。

交付的 Release APK 使用此项目独立签名，未启用调试。后续更新需要保留工作区 `.signing` 中的签名文件及密码文件；请自行离线备份，勿公开。源码包可独立构建调试 APK；自行制作 Release 时需配置自己的签名。更换签名后不能覆盖安装现有版本。
