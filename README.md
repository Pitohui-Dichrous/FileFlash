# FileFlash · 鸿蒙 4.2 兼容测试版

Android / iPhone 局域网文件与文字互传。

[下载兼容测试 APK](https://github.com/Pitohui-Dichrous/FileFlash/releases/download/v0.1.1-harmony4.2.1/FileFlash-0.1.1-harmony4.2.1.apk)

本分支尝试兼容鸿蒙 4.2，可由鸿蒙手机开启共享，iPhone 用 Safari 扫码收发，两台设备连接同一个 Wi-Fi。

最低兼容 API 调整为 29，尚待 Mate X5 真机确认。[安卓主线](https://github.com/Pitohui-Dichrous/FileFlash/tree/main)保持原样。

支持文件和文字互传、断点续传、自动与手动清理缓存。无账号、无广告，传输不需要互联网。
